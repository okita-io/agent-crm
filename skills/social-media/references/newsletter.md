# Newsletter issue draft

Write one newsletter issue as a document. Adapted from Charlie Hills' newsletter-voice skill. Sending is **not implemented** in this CRM. tactic.studio mail stays gated by Pete.

This is not marketing-agi `email.md`. That module designs **sequences** (welcome, nurture, launch). This module drafts a **single issue** in brand voice.

## Prerequisites

- brand-context Voice (required)
- Optional: 2+ past issues as samples. If none, pick an archetype and label the draft **archetype-based — revisit after 5 issues**.

## Archetypes (when no samples)

| Archetype | Use when |
|-----------|----------|
| Data tutorial | Frameworks, steps, prompts (HeyBuddy ops, tactic.studio how-we-ship) |
| Contrarian essay | A held position with a named opposition |
| Case study teardown | One subject, public sources only, `[NEED:]` for missing proof |
| Curated digest | 5–7 links with commentary (needs a niche pulse) |
| Personal essay | Only if Voice allows it and a real story exists |
| Interview / profile | Only with a real, permitted subject |

Do not invent a signoff phrase. Do not invent a subscriber count.

## Issue structure

1. **Opening** — specific result, observation, or claim. Say what this issue gives the reader.
2. **Body** — 5–8 sections max. One job.
3. **Evidence** — numbers only from brand-context proof or quoted sources with URLs
4. **Close** — forward-looking next issue or a single human-gated CTA. No fake urgency.

Length: 600–1,200 words unless samples show a different range.


Run `slop-patterns.md` on the issue body.

## Rules

- Never claim the issue was sent or scheduled
- Curated digest links must be real URLs from the pulse or scrape
- tactic.studio: no list-buy language, no "quick call" CTAs in the body
- Sequences (drip, launch) still go through marketing-agi `email.md` and stay unsent
