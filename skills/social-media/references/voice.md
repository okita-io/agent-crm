# Voice from samples

Deepen the **Voice** section of a brand-context file using 3–5 real writing samples. This is not a Cowork interview and not `about-me.md`. Product, ICP, and constraints already live in `brand-context.{brand}.md`. This module only answers: how does this brand actually write?

## When to run

- Brand-context Voice is a few adjectives and a banned-word list
- Someone pastes posts, emails, landing copy, or newsletter issues and wants future drafts to match
- Two brands would otherwise sound the same in Spark output

Skip if there are fewer than 3 samples. Ask for more rather than inventing a profile.

## Inputs

1. The existing brand-context file (required)
2. 3–5 samples with source labels (`linkedin post 2026-03`, `homepage hero`, `newsletter #12`). Samples may be the brand's or a voice they want to borrow — say which.
3. Off-limits already in brand-context (do not contradict them)

## Extract (patterns across samples, not one-off quirks)

**Voice signals:** average sentence length; paragraph rhythm; hook style; point of view (we / you / observational); tone; signature phrases; CTA / close.

**Structural signals:** length range; lists vs prose; how pieces open and close.

**Absence signals:** punctuation, hook types, tones, or constructions missing from every sample. Only list absences you can point at. "Never uses em dashes (0 of 5 samples)" is valid. A generic banned-words list is not.

If samples contradict each other, record the contradiction. Do not smooth it over.

## Output — append or replace Voice only

Do not create a separate `about-me.md`. Update the **Voice** section of `brand-context.{brand}.md` (or a sibling `voice.{brand}.md` if the brand-context file must stay short). Keep the whole Voice block under 400 words.

```
## Voice

**How we sound:** [2–3 sentences from the samples, not adjectives from memory]

**How we never sound:** [tones absent across samples + existing brand-context bans]

**Sentence rhythm:** [length, pacing, paragraph breaks, one absence]

**Hook patterns:** [3–5 types observed, one short example each from samples]

**How we open / close:** [1–2 sentences each; note avoided closings]

**Words we use / avoid:** [merge with existing lists; do not drop ranch constraints]

**What this voice never does:** [3–5 behaviours backed by absence in the samples]
```

## Rules

- Work from the samples. Do not invent patterns.
- Keep ranch constraints (no invented proof, no outbound send, tactic.studio gate).
- Do not copy Charlie Hills' British-English / no-em-dash house style unless the samples actually do that.
- If the samples are American and the brand-context is mixed, follow the samples and say so.
- Never treat a competitor's copy as ours without labelling it as a borrowed voice.
