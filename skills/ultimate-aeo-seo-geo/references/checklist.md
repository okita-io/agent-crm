# Ultimate checklist (Agency excerpt)

Use alongside `aeo-geo/references/aeo-geo-review.md`.

## Score the five levers

Extractability · Evidence · Entity · Corroboration · Access — each 0–100 heuristic; state gaps as `[NEED]`.

## Ship blockers

- Answer not in HTML / behind JS or login
- No self-contained answer under the question heading
- Zero cite-worthy facts (model could invent the page)
- Inconsistent brand entity across About / schema / social
- robots accidentally blocking wanted search crawlers

## One action this week

Pick the highest-leverage owned-page fix that unblocks extractability or entity clarity. Everything else is backlog.
